# Halloween ASCII Art 🎃

Консольное приложение, которое рисует ASCII-арт на Хэллоуин.

## Установка
git clone https://github.com/hbabayan939-cmd/halloween-art.git
cd halloween-art
pip install -e .

## Использование
halloween pumpkin
halloween ghost --color
halloween all -c -a
