# Halloween ASCII Art 🎃

Console art in halloween theme, created for fun.
Please if you like this project help me for promoting this project.

## How to install
1. git clone https://github.com/hbabayan939-cmd/halloween-art.git
2. cd halloween-art
3. pip install -e .

## Usage
1. halloween pumpkin
2. halloween ghost
3. halloween skeleton 
4. halloween <any> --color
5. halloween all -c -a
