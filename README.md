# Halloween ASCII Art 🎃

Console art in halloween theme, created for fun.
Please if you like this project help me for promoting this project.

## How to install
git clone https://github.com/hbabayan939-cmd/halloween-art.git
cd halloween-art
pip install -e .

## Usage
halloween pumpkin
halloween ghost
halloween skeleton 
halloween <any> --color
halloween all -c -a
